# Copiloto_Corporativo
Assistente corporativo inteligente desenvolvido para a disciplina IA Generativa Aplicada ao Desenvolvimento.
Sobre o projeto

O projeto simula um assistente interno capaz de receber perguntas em linguagem natural e gerar respostas com apoio de IA, utilizando uma base de conhecimento corporativa simulada.

A proposta é demonstrar como a IA Generativa pode facilitar o acesso a informações organizacionais e também acelerar o próprio desenvolvimento de software.

  Objetivos

Permitir consultas em linguagem natural.

Utilizar IA como funcionalidade principal.

Responder com base em uma base de conhecimento controlada.

Demonstrar desenvolvimento assistido por IA.

Aplicar boas práticas de uso responsável da IA.

  Como executar

Acesse a aplicação publicada: [https://copilot-corp-assist.lovable.app]

Abra o chat.

Faça uma pergunta relacionada à base de conhecimento.

Observe a resposta gerada pela IA.

Exemplos

Como abro um chamado de TI?
Como solicito férias?
Onde encontro informações sobre benefícios?
Qual é o procedimento para problemas de acesso?

Também é possível testar uma pergunta fora da base para verificar se o assistente informa que não encontrou a informação.

  Uso de IA no desenvolvimento

A IA participou de diferentes etapas do projeto:

definição da arquitetura inicial;

geração da interface;

criação do fluxo de chat;

elaboração e refinamento de prompts;

ajustes de usabilidade;

revisão da documentação.

  Uso responsável

O sistema deve evitar inventar informações. Quando uma informação não estiver disponível na base de conhecimento, o assistente deve informar que não encontrou a resposta.

Não devem ser utilizados dados corporativos reais ou informações pessoais sensíveis na demonstração acadêmica.

  Limitações

Esta é uma versão acadêmica e demonstrativa. A base de conhecimento é pequena e simulada. Uma solução real exigiria autenticação, controle de acesso, segurança, monitoramento, avaliação das respostas e integração segura com sistemas corporativos.
